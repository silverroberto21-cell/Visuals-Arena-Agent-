# Thème : Les 5 clés pour vivre une vie chrétienne victorieuse — ROUGE

- **Occasion** : message d'enseignement / culte du dimanche (acrostiche ROUGE)
- **Ambiance** (2 mots) : combativité, clarté
- **Couleur imposée** : **ROUGE** — traité comme l'**accent** du visuel (~10 %) : le mot
  acrostiche, les cinq lettres-clés et les filets. Jamais en fond : le bleu du fond fourni reste
  la dominante (~60 %).
- **Duo de polices** : **Anton** (titre, mot-acrostiche, verbes-clés — capitales condensées
  très grasses, lisibles à 320 px) + **Jost** (gloses et références — géométrique, très lisible
  en petit)
  → *l'acrostiche doit se lire lettre par lettre d'un coup d'œil : un titre de caractère pour
  les cinq clés, une géométrique neutre pour tout le texte qui les accompagne.*
- **Script / lettrine** : aucune — l'accent du thème est **la couleur** et **la lettre**.
- **Accents** : rouge vif `#DE2638` (mot ROUGE, lettres-clés), rouge clair `#FF6A60` (haut du
  dégradé), filets rouges ; acier `#B0D6F6` pour les gloses et la signature.
- **Traitement du fond** : FOND 6 (`f06-bleu-acier-texture.jpg`) — texture toile bleu acier,
  lumière rasante du coin haut droit, assombrie de 10 %, scrim vertical + halo cyan conservé ;
  souffle rouge très diffus dans l'angle bas gauche pour accorder l'accent.
- **Secondaires types** : acier clair `#B0D6F6` + cyan du fond `#0AB0D9` + blanc froid.
  Le rouge reste **unique** : aucun rouge de modèle, aucune couleur inventée.
- **À éviter** : peindre le fond en rouge (le bleu doit rester majoritaire), empiler les effets,
  séparer la lettre de son verbe, oublier une référence biblique.
- **Formats déjà servis** : visuel 1280×720 (2026-11-07) + **miniature YouTube 1280×720**
  (`scripts/render_rouge_5cles_theme.py`) — **le thème seul, sans les points** : accroche,
  mot-acrostiche, phrase du thème ; une clé filaire et cinq pastilles rouges disent le sujet
  sans un mot de plus. Les cinq verbes et leurs références restent sur le visuel 1280×720.
