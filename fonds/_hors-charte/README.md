# /fonds/_hors-charte — fonds non conformes

Ces fichiers **ne sont jamais utilisés tels quels**. Ils sont conservés parce qu'ils peuvent être
**ramenés au bleu** sur demande, pas parce qu'ils sont utilisables en l'état.

## Contenu

| Fichier | Pourquoi il est ici | Ce qu'il faudrait faire |
|---|---|---|
| `f18-violet-magenta-stries.jpg` (ex-`FOND 18`) | 76 % violet/magenta, 24 % orange : **aucun bleu** (mesuré) | Virage complet vers le bleu, ou reconstruction d'un dégradé bleu dans le même esprit de stries |

## Règle applicable

La consigne impose le bleu comme dominante (~60 %, visible au premier regard). Un fond qui n'est
pas bleu relève du cas 3 de la palette (`specs/palette.md` § 4) :

1. recalage de teinte vers le bleu, ou
2. voile/dégradé bleu en superposition (60–80 % pour un violet aussi dense), ou
3. remplacement par un fond bleu construit dans le même esprit.

Dans les trois cas, le geste est **signalé dans la note**, ligne 1. Tant que ce n'est pas fait, le
fichier reste ici : un fond violet utilisé tel quel est un échec de livraison.
