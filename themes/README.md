# /themes — fiches de thème

Une fiche par thème. Elle **prime** sur le choix libre de polices : si une fiche existe, l'agent
l'applique sans re-discuter.

## Convention de nommage

```text
<theme>.md        ex. atmosphere-de-priere.md
                  ex. jeunesse-debout.md
```

## Modèle de fiche

```markdown
# Thème : Atmosphère de prière

- **Occasion** : veillée de jeûne et de prière
- **Ambiance** (2 mots) : recueillement, profondeur
- **Duo de polices** : Anton (titre, capitales condensées) + Rubik (texte)
  → *un titre qui tient en 3 mots sans faiblir en vignette, un texte qui garde les horaires lisibles en petit.*
- **Script / lettrine** : Great Vibes, une seule lettre du titre — jamais d'information pratique.
- **Accents** : lettre décorative laiton en tête de titre, filet fin sous la date.
- **Traitement du fond** : dégradé vertical, sombre en haut, lueur basse ; grain léger.
- **Secondaires types** : couleur de la tenue de l'orateur + laiton (#C9A227) + blanc bleuté.
- **À éviter** : couleurs saturées, empilement d'effets, titres de plus de 3 lignes.
- **Formats déjà servis** : miniature 1280×720, story 1080×1920, flyer A5.
```

## Rôles

| Champ | Effet sur la production |
|---|---|
| Duo de polices | verrouillé pour **tous** les formats du thème |
| Script / lettrine | autorisé en accent uniquement |
| Ambiance | guide les choix d'effets (halo, grain, vignettage) |
| Secondaires types | accélère la construction de la palette, sans remplacer les nuances du fond |
| Formats déjà servis | sert de mémoire pour décliner un nouveau format |

## Règles

- Une fiche = un thème, pas une série d'événements.
- **Nouveau thème = nouvelle réflexion typographique**, sauf fiche existante ou police imposée.
- Une fiche se met à jour quand un format est ajouté (dernière ligne), pour garder la cohérence.
