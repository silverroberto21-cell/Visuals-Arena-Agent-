# /essais — recherches avant livraison

Rendus de travail, **pas des livrables**. Ils servent à comparer des fonds, des polices, des
traitements, et à garder la trace de ce qui a été montré avant validation.

## Convention

```text
<AAAA-MM-JJ>/miniature-fond<NN>.jpg     un fichier par fond essayé
<AAAA-MM-JJ>/planche-*.jpg              les quatre côte à côte
```

## Règles

- Un essai **n'est pas livré** : il ne va jamais dans `livrables/` sans validation.
- Les essais se gardent — c'est la mémoire des comparaisons déjà faites (ne pas reproposer
  un fond ou une police déjà écartés).
- Le rendu est rejouable : chaque série a son script dans `scripts/`.
- Un essai validé devient un livrable : il est recopié dans `livrables/`, renommé, daté, et sa
  note de livraison est écrite à ce moment-là.
